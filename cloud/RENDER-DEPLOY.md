# KRC GROUP Central Server — Render Free + PostgreSQL

This version uses PostgreSQL instead of SQLite, so the Render Web Service does not need a paid persistent disk. A free PostgreSQL provider such as Neon can hold the central users, permissions, modules and activity data.

## Render Web Service
- Runtime: Node
- Region: Singapore
- Plan: Free
- Build command: `npm install`
- Start command: `npm start`
- Health check: `/health`
- No Render persistent disk is required.

## Environment variables
Set these in Render:
- `DATABASE_URL` = your PostgreSQL connection string
- `ADMIN_USERNAME` = `admin`
- `ADMIN_PASSWORD` = choose your admin password
- `SESSION_SECRET` = auto-generated by Render
- `TZ` = `Asia/Kolkata`
- `KRC_CLOUD_API_URL` = leave empty on the central server

## First start
The server automatically creates its PostgreSQL tables, the first admin account, and the 16 default KRC modules when the database is empty.

## Desktop clients
After Render gives you the service URL, set `KRC_CLOUD_API_URL` in the desktop client build to that URL. Then all desktop PCs use the same central users, passwords, permissions and modules.

The dashboard clock uses `Asia/Kolkata` explicitly, so it does not depend on the Windows PC's local timezone.
